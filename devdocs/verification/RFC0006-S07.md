## Known deviations and honest scoping

1. **Native scenario deferred**: `scripts/tests/workbench/vault_source_preview.py` exists (gate-registered) but the `workbench-visual-linux.sh --scenario vault-source-preview` run is not executed in this slice (matches the S06 precedent; requires Xvfb/xdotool/OCR data). The receipt marks the OCR pixel probe `incomplete`, never pass.
2. **Preview TTL enforced on access; abandoned-preview GC deferred** to S11 (NFR-14). The store's `remove_job`/expiry sweep plumbing exists; background GC is S11 work.
3. **Selection is session-local** in S07 (D-09: "selection revision and digest", not mutation of the sealed plan); persistence of the selection record with the manifest is wired when S08's Apply lands.
4. **One chord, one panel**: `workspace.open_replace_view` (Mod+Shift+F) opens the vault Find/Replace panel with an explicit Find/Preview toggle; the spec's separate Mod+Shift+H preview chord is not bound (cosmetic keyboard surface, recorded).
5. Full RFC-0006 conformance (S00–S11, AC-1–26 incl. all-platform native receipts) is not claimed; see §10.

## Exit criteria mapping (S07)

- FR-8 (complete frozen scope, page all matches, report exclusions, never substitute full-text offsets): implemented + tested (exact totals, continuation, per-note pages, typed exclusions; no `search_notes`/full-text path in preview).
- FR-9 (sealed preview: input/output hashes, selection revision, source guards before Apply): implemented (schema-1 manifest, content-addressed payloads, NoChange, lineage, selection revision/digest; Apply absent).
- AC-11 read/preview portion (changed disk/buffer/path/grant after preview → zero note effect): preview is pure read (no mutation tests), stale finder → typed expired, dirty/conflicted/orphaned excluded with counts; note-level “stale at apply” is S08.
- AC-17 read/preview portion (hostile IDs/paths/grants): op-store containment, key/native identity handling, facade arg validation (`deny_unknown_fields`, hex-id checks), read-only report — tested.
- AC-19 read/preview portion (no truncated complete report): `truncated_scope` exposed; `LimitExceeded` typed; no “0 of 0”; exclusions countable — tested.
- Sealed manifests/diffs reproducible from exact bytes: byte-verified payloads, deterministic record digest, content addressing — tested.
- No destructive command exposed prematurely: `replace.apply/cancel/resume/revert/forget` are not registered anywhere (grep-verified).
