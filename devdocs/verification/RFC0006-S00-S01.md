## Scope delivered

### S00 — Encoding-preserving note lifecycle (D-15/§6.10)

- Canonical `flavite-encoding` crate (from the parallel branch) adopted; RFC systems the
  integration requires were ported into it additively: `FormatStamp`, `CODEC_VERSION`,
  `FileEncoding::{code,from_code}`, `SourceFormat::{bom,bom_len,bom_bytes,encoding_code}`
  + const constructors + `Default`/`Display`, `default_envelope()` limits,
  `NOT_CANCELLED`, `DecodedContent::source()`. Exactly one implementation of each system.
- `flavite-vault/src/encoding.rs`: device-local `EncodingHintsState` (schema-1 hints
  record, ArcSwap publication, hash-bound confirmations, pre-save `BindingIntent`),
  `resolve_source` (explicit > matched hint > Auto; NUL-bearing BOM-less gate;
  stale-hint re-confirmation; typed `ChoiceReason` payloads with observed raw hash).
- Session open path decodes once through `resolve_source` (`open_note_snapshot` attaches
  the validated snapshot; no empty fallback ever installs). Undecodable/ambiguous sources
  produce `ActionRequired("encoding-choice-required", {reason, raw_hash, allowed})`.
- Save refuses unencodable strict-ASCII drafts with zero filesystem effects
  (`encoding-unencodable`), persists format-binding intents before the source effect,
  binds hints on the durable receipt and retires intents after metadata durability;
  open completes provably matching intents (`EncodingMetadataPending` resolution).
- Reopen (`note.reopen_encoding`, ReadNotes + exact raw hash + dirty/pending-save
  guards, BomMode auto/present/absent semantics) and Convert
  (`note.convert_encoding`, WriteNotes + exact revision, isolated Undo boundary,
  representability preflight) wired through the API facade and the UI banner/indicator.
- External changes, merge (base/mine/theirs decoded under captured descriptors, merged
  as decoded layers), history restore (codec-decoded, BOM descriptor-owned) and
  recovery v2 (recorded format replay) are descriptor-aware.
- Index cache rebuilt as schema 4.0: `encoding`/`bom`/`decode_status` columns, codec
  marker in meta, decode-once ingestion with `undecodable` typed status, source-span
  recomputation through the composed codec map. Old 3.x caches rebuild under a new epoch.
- UI: per-tab `host/encoding.rs` (typed decisions, Reopen/Convert/Cancel banner,
  source-format indicator on the note footer); async open completions record the banner
  (the cold-open flight path).
- CLI: `encoding <note> reopen|convert` subcommands driving the core commands; format
  reporting; core re-verifies raw-hash preconditions.

### S01 — Literal note replacement spine (D-05/D-06/D-12)

- Canonical `flavite-text-search` crate adopted (literal + regex matcher, UAX #29
  whole-word via the shared `flavite_syntax::text::word_boundaries` primitive, Unicode
  simple folding, frozen scopes, checked replacement templates).
- Buffer: `prepare_batch`/`install_prepared`/`try_apply_batch` — validation before any
  state change (typed `BatchError`), one combined edit, one isolated Undo node with an
  after-state snapshot built off the interactive turn, affected-range EOL splice proven
  byte-exact against a whole-reference oracle. `UndoPolicy::{Isolated,Typing}` with
  `Isolated` as the default (clients cannot bypass boundary isolation); the editor's
  captured typing path requests `Typing` explicitly.
- Vault: `text_edit.rs` prepare workers (2) + core-issued u128 plan registry — 64
  unconsumed plans / 30 s TTL / 2,048 replayable receipts / 10 min result window,
  admission sweep reclaims without restarts; `ApplyReplace` re-runs buffer/revision
  guards and installs one isolated batch; duplicate requests replay the same receipt.
- API: `text.prepare_replace` (read) / `text.apply_replace` (write, scoped target)
  commands with `deny_unknown_fields` DTOs; `apply_edits` gains `undo_policy`
  (default `Isolated`).
- UI: `host/note_search.rs` extraction (FindState/matching/navigation out of
  reading.rs — no forwarding duplicates, zero `match_indices` in the UI crate),
  Replace next/all through the core plan flow with stale/expired states, Mod+H chord,
  read-mode find, accessibility nodes from the same catalog.
