## Scope delivered over the recorded S04 commit

The HEAD commit already delivered the typed-intent spine, the reworked
gesture arbiter, the overlay-band chrome, destination memory, the native
runner/scenario and the gate/xtask fixtures. Review against the RFC found
and closed the following gaps in this receipt's working set:

1. **Formatting gate red at HEAD** — `cargo fmt --all -- --check` failed on
   `views/graph.rs` as committed; fixed.
2. **D-02 frozen hold vs `Updating` frames** — the router discarded
   navigation click pairs while a newer semantic frame was accepted and
   pending presentation (`updating`/`stale`/`!graph_is_current`). D-02
   requires the pair to survive on the frozen hit geometry, with only
   explicit Insert keeping the current-paired-frame requirement. Both the
   pointer router (`handle_graph_action`) and the accessible-list router
   (`GraphNodeCommand`) now share the epoch-keyed rule for navigation and
   keep the exact-frame rule for insertion/drag.
3. **D-02 hit-geometry freeze enforced** — while a pair hold is pending,
   entity-moving geometry rebuilds (base publication, position ticks,
   shared pins, node visibility, drag previews) are deferred until the
   bounded hold ends; emphasis-only updates (selection, writing-target
   accent, palette) still apply. The hold expires with the configured pair
   interval (`GestureArbiter::expire`), deferred frames catch up on the
   next pump, and camera auto-fit does not move while a hold is pending.
4. **Retired-contract copy removed** — the writing-target banner and the
   list-mode footer still advertised "double-click … to insert its link"
   (the RFC-0003 D-05 behavior this slice amends). Both now state the
   amended contract; cumulative S04 source gates keep them dead, and the
   stale `arrives with W09` deferrals are gone (inspector and
   Create/Locate ship here).
5. **FR-15 availability parity** — the selection band hard-coded
   `enabled: true` for Open/Insert; chips now derive from the same
   predicates that gate execution (`insert_available`, resolvable
   locator). The palette gains `graph.create_from_node`/`graph.locate_node`
   with the same predicates; Enter/Ctrl+Enter/keyboard/palette/band/AT all
   route the same commands.
6. **D-02 attachment activation** — attachment nodes now drive the
   existing local attachment inspector (core-validated
   `QueryPayload::AttachmentOpen`, token-owned by the graph tab, duplicate
   in-flight refusal, honest typed completion routed with no note open).
7. **D-02 unresolved nodes** — activation of an unresolved target offers
   explicit Create (the canonical prefilled, validated new-note dialog via
   the existing `offer_create_for_link` path) and Locate (prefixed
   picker), never creating implicitly (FR-19; zero tab/file effects).
8. **D-03 multi-open honesty** — `Open selected in tabs` reports
   opened-of-requested counts derived from committed tabs; refusals never
   inflate the count.
9. **Test-runner hygiene** — three `__pycache__/*.pyc` artifacts committed
   at HEAD were untracked and `__pycache__/` added to `.gitignore`
   (regenerable output must not be tracked).
