# RFC-0003 W08 implementation and verification record

Date: 2026-10-31. Status: integrated behavior implemented; **full RFC slice conformance remains incomplete** for the specific obligations below. This is not a waiver of W01 or of the resource, native-input, and performance requirements. W09–W14 capabilities are not claimed here.

## Review and scope

The supplied concept communicates three independent things: the note being written, the graph's selection, and the context tool's source. Its useful acceptance target is that separation through rearrangement and exploration. Its sample notes, counts, colors, and geometry are not test expectations. The ignored concept asset is not read by a build or test; `scratch-devdocs/` remains ignored.

The inspected working tree already contained substantial W07 integration. The old graph path still described saved relationships, rebuilt topology versions inconsistently, and lacked revisioned outgoing replacements, real structural filtering, and occurrence removal. This change integrates those paths with the actual Session, parser, resolver, API, workspace reducer, and mounted graph/editor. It preserves the pre-existing working-tree work; no historical-shell rollback or parallel mutation authority was introduced.

## Delivered paths

* `flavite-graph-protocol` contains bounded, toolkit/IO-free graph scopes. Predicates are typed AND/OR/NOT groups, tags, exact native path prefixes, scalar properties, and canonical saved queries. Neighborhood traversal runs on the eligible induced graph, with explicit excluded/missing roots, depth 0–6, and In/Out/Both directions. Attachments, embeds, and unresolved targets are independent opt-in layers. Invalid drafts retain the previous scope. Nested persisted conditions remain active and require explicit Clear before the compact editor replaces them.
* The API graph service combines a consistent saved base with replacement outgoing sets from revisioned open-buffer snapshots. Dirty titles, tags, properties, edges, and occurrences carry buffer provenance. Save/index coverage retires an overlay only when content and base hash match; unrelated generations, a later edit, and Undo cannot retire it. Parse failures are unavailable current data, not successful empty parses. The saved base remains separately available in the API.
* Scope results carry view incarnation and sequence. Geometry, hit identity tables, click arbitration, and API actions retain version keys. Stale results and pointer/accessibility actions are refused. Filtering retains selection outside the scope and never chooses an editor or moves its caret. Counts distinguish base, matching, rendered, and omitted entities. Graph selection remains separate from the writing target and Preview source routing.
* The running graph has filter controls, reversible scopes, neighborhood controls, selected membership, bounded multi-selection, a filtered/paged list, source/direction/provenance occurrence rows, and a revisioned occurrence chooser. Removing a chosen occurrence opens its source, verifies the exact scanner span and source revision/hash, prepares a guarded plan, and applies one standalone Undo unit. Repeated links, surrounding prose, reciprocal links, and the destination note remain unchanged. Unresolved occurrences are removable; a target that resolves after preparation requires a new choice.
* Preview reads current open-buffer text and distinguishes unsaved content from saved snapshots. Backlinks use current outgoing replacements, aggregate occurrences by source, and retain saved/unsaved provenance. Saved full-text query membership remains separate from dirty structural metadata.
* Both GPU and canvas consume the same geometry and input recognizer, with bounded visible labels. Freeze retains existing node positions through selection, filtering, and publication changes. The source-target affordance remains visible. The Linux runner exercises real pointer/keyboard input and checks actual source bytes and destination immutability.

## Evidence

The commands and outcomes for the final working tree are recorded in the local `target/workspace-evidence/w08/` logs and manifest. Window runs have their own run IDs, source-tree SHA-256, Cargo.lock BLAKE3, backend, semantic trace, screenshots, and `graph-checks.json`. Evidence is from disposable fixture vaults. A working-tree fingerprint is required because HEAD alone does not identify these uncommitted changes.

The test set includes `graph_projection`, `link_occurrences`, `semantic_links`, `graph_filter_context`, `graph_identity`, `scopes` (1,024 randomized independent BFS comparisons), `revision_history`, scope-codec round trips and rejection, link-store expiry/capacity, and worker-panic schedules. Existing workspace tests include the 100,000-operation layout campaign. The scope protocol crate's measured line coverage is 182/182 (100%).

Fuzz smoke uses the actual canonical algorithms: `graph_scope`, updated `workspace_layout`, `workspace_restore`, and `link_insertion`, each for at least 60 seconds. The first insertion run exposed an incorrect fuzz-oracle error-precedence assumption for a simultaneously unparsable source and mid-codepoint caret. The corrected oracle still requires rejection, and valid-coordinate unparsable sources must still return the parse error. The exact repro is a tracked syntax regression. No successful proof or mutation assertion was removed. Initial sandbox LeakSanitizer process-inspection failures were rerun outside the sandbox with sanitizer checks enabled; they are not passing campaigns.
