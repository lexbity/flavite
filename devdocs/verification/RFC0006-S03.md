## Delivered in this working tree

- Regex execution is registered through the shared note-search API. The UI only owns
  per-view options, pages and admission; it does not compile regex or scan source.
- The framed helper protocol is version 3. Find requests carry a zero-based match
  ordinal, and replies have bounded paged spans plus a terminal total. Large captured
  expansions are split across bounded chunks; the parent checks sequence, offsets,
  lengths and aggregate output limits before accepting a completed result.
- The vault Find API returns exact `total_matches`, page `offset`, `next_offset`, and
  `truncated`. The UI continues at page boundaries and wraps Previous/Next without a
  10,000-match prefix masquerading as the whole note. The match count and page range
  are exposed in the Find bar.
- The helper remains an exact sibling of the running executable. Linux uses a process
  group and an address-space ceiling; deadline/cancel terminates and reaps the child.
  Unsupported cursor/edit/filesystem command variants are not part of the wire enum.
- Added focused API, UI, helper, protocol, 128 KiB expansion, 600-match continuation,
  error, cancellation, wrong-engine and missing-helper tests. Added `text_match` and
  `text_worker_protocol` fuzz targets. Added the fixed 12-case reference pattern
  corpus at `crates/flavite-text-search/tests/fixtures/performance-patterns.json`; a
  test ensures every case remains valid and produces its pinned match/no-match result.
  Setup and app guides describe the helper installation location and regex
  replacement syntax.
- Added a `note-regex-replace` Linux OS-input scenario. The first attempt reached the
  app but found the host lacks Tesseract English data; the scenario was changed to use
  the actual keyboard focus order and no longer requires OCR. The retry then could not
  start a reachable Xvfb display (`DISPLAY=:100` was unavailable and the newly started
  Xvfb exited before accepting connections). Thus the scenario source exists, but no
  rendered OS-input receipt is claimed.
